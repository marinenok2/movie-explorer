# React Movie App 🎬

A movie discovery web application built with React.

## Features
- Search for movies
- Browse movie collections
- View movie details
- Add movies to favorites
- Login and registration pages
- Light and dark theme

## Technologies
- React
- JavaScript
- Vite
- React Router
- SCSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
